**🚀 Modern Developer Portfolio**  
A sleek, responsive, and performance-oriented developer portfolio built with **React 19**,  **Vite**, and  **Tailwind CSS**. This portfolio dynamically showcases GitHub repositories with curated imagery and professional fallbacks.  
**✨ Features**  
- **Dynamic GitHub Integration**: Automatically fetches your latest repositories using the GitHub API.  
- **Curated Project Mapping**: High-quality Unsplash imagery manually mapped to key projects for a professional look.  
- **Smart Image Fallbacks**: Custom GitHub-branded placeholders for projects without curated images or failed loads.  
- **Modern UI/UX**: Built with a "Neon Cyan" dark theme, featuring smooth animations powered by  **Framer Motion**.  
- **Responsive Grid**: Optimized 3-column layout on desktop that scales gracefully to mobile devices.  
- **Interactive Elements**: Hover effects, smooth scrolling, and animated transitions.  
**🛠️ Tech Stack**  
- **Frontend**: [React 19](https://react.dev/ "https://react.dev/")  
- **Build Tool**: [Vite 8](https://vitejs.dev/ "https://vitejs.dev/")  
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/ "https://tailwindcss.com/")  
- **Animations**: [Framer Motion](https://www.framer.com/motion/ "https://www.framer.com/motion/")  
- **Icons**: [React Icons & ](https://react-icons.github.io/react-icons/ "https://react-icons.github.io/react-icons/")[Lucide React](https://lucide.dev/ "https://lucide.dev/")  
**🚀 Getting Started**  
**Prerequisites**  
- Node.js (Latest LTS recommended)  
- npm or yarn  
**Installation**  
1. Clone the repository:  
2. git clone https://github.com/sudo-aadarsh/project-1-Portfolio-.git  
   
3. Install dependencies:  
4. npm install  
   
5. Start the development server:  
6. npm run dev  
   
7. Build for production:  
8. npm run build  
   
**📂 Project Structure**  
- src/components/: Modular React components (Navbar, Hero, Projects, etc.)  
- src/assets/: Static assets and images.  
- public/: Public assets like icons and favicons.
